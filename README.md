# card-delivery-allure

Домашнее задание к занятию «4.1. Репортинг» (Netology).

## О проекте

Автотесты для сервиса доставки банковских карт, написанные с использованием:
- **Selenide** — управление браузером;
- **JUnit 5** — фреймворк для тестов;
- **Allure** — генерация отчётов;
- **JavaFaker** — генерация тестовых данных.
